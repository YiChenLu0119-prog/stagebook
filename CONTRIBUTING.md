# Contributing

Help improve a specific rehearsal task. Describe what you were trying to do, where the editor got in the way and the behavior you expected.

For bugs, include the app version, browser, opening/saving method and minimal steps. Use exact times when relevant. Prefer the generic example and remove private production material.

For changes, edit `src`, build and run the relevant checks in [development notes](docs/development.md). Verify interaction changes in an independent browser, including saving and reopening. Explain the resulting behavior and any limits in the pull request.

Keep actions at the playhead, keep actor edits from unexpectedly seeking or changing views, preserve existing file compatibility, and keep deletion undoable. UI language must remain independent of character names, lyrics and notes. Translation changes should preserve placeholders, actual filenames and readable layouts.

Use synthetic fixtures and public examples. Do not commit production soundtracks, full song lyrics, private exports, recovery drafts or personal paths. Contributions must be compatible with GPL-3.0-only and retain required notices.
