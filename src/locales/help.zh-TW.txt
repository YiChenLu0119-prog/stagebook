走台本 · 多語言版 v9.1

介面語言
頂部可切換「简体中文 / 繁體中文 / English」，並記住個人選擇。切換時保留播放位置、步驟、選擇與時間軸縮放；角色名稱、歌詞及備註保持原文。匯出的 HTML 會附上介面語言，檢視者已有的個人設定優先。三種語言均可離線使用。

打開與儲存
解壓後只有「走台本.html」和「演出资料」兩個入口。
用瀏覽器打開「走台本.html」。應用完全離線。
打開即載入包內走台、歌詞與音樂。要繼續其他版本，點「匯入走台」選擇完整資料夾或 ZIP。舊演出包仍可匯入。
⌘ / Ctrl + S 儲存：已連接資料夾時寫回；未連接時可下載演出包。已有 JSON 會先備份。
發給演員：點「發給演員」下載 ZIP，對方解壓後按同樣方式打開並匯入資料。
瀏覽器恢復草稿用於意外恢復；正式保留請儲存檔案。

編排一小步
1. 點下方步驟卡片，或用上方步驟選擇框切換。
2. 拖動演員擺落點；淡色圈是起點。選中演員，右側寫「本步動作備註」。
3. 拖路線中間的圓點改彎度；要經過多個位置，點右側「路徑節點」。
4. 定位到需要的音樂時間，點「＋ 新增動作」或按 N；所有入口都在播放指針處新建，保留目前時間軸或步驟視圖。點「預覽本步」檢查。
拖動落點、寫備註和調整演員時長都不會移動音樂指針；本步開始與結束時間一直顯示在上方。
Shift + 點擊或從空白處拖框可多選，整體移動或排列站位。多人動作說明會寫到各人的本步動作里，並保留已有備註。舊版共同提醒仍會顯示在對應演員旁。
右側方向微調和「移到指定位置」可按舞台區域擺位，無需輸入座標。
「舞台工具」可對照起點和落點、顯示全部路線、開網格、旋轉與調整舞台。
「銜接下一條路線」預設開啓：調整落點時銜接原本相連的下一段起點，保留後續落點。

刪除與右鍵
目前步驟旁直接有「刪除本步」，無需進入詳情。
選步驟按 Delete / Backspace 刪步驟；選演員則刪他在本步的行動，保留角色名單。
點「路徑節點」後，點選中間經過點再按 Delete，或點列表旁的「刪除」。起點和終點保留。
選彎度控制點按 Delete 可恢復該段直線。每種刪除都能用 ⌘ / Ctrl + Z 復原。
右鍵步驟、演員、路線或節點，可直接預覽、複製、改時間、新增節點或刪除。

常用快捷鍵
空白鍵：播放 / 暫停；Shift + 空白鍵：預覽本步。
[ / ] 或 PageUp / PageDown：上一步 / 下一步；Home / End：首步 / 末步。
N：在目前播放位置新增動作，保留目前視圖；⌘ / Ctrl + D：複製目前步驟；F2：重命名。
方向鍵：微調所選演員或節點；Shift 加大幅度。沒選演員時左右切步驟。
⌘ / Ctrl + A：全選；⌘ / Ctrl + C / V：複製 / 貼上站位。
E：路徑節點；V：返回擺位；Esc：關閉菜單或逐級取消選擇。
⌘ / Ctrl + Z：復原；⌘ / Ctrl + Shift + Z：重做。
⌘ / Ctrl + O：匯入；⌘ / Ctrl + K：搜尋。
+ / − / 0：放大 / 縮小 / 適配目前視圖；?：查看完整快捷鍵表。
輸入框內保留正常的打字、文字刪除、複製貼上和文字復原。

時間軸與演員移動時間
切到「時間軸」，用滑桿、＋ / − 橫向放大，播放指針會留在視野中；⌘ / Ctrl + 滾輪圍繞滑鼠位置縮放，0 適配整曲。點擊底部時鐘可直接輸入「01:25.6」或秒數定位。
演員色條：拖中間改開始時間，拖兩端改起止時間，不會移動整個步驟或其他演員。
選演員後，右側「移動時間」可設定開始前等待和移動用時。例如一步 10 秒，等待 2 秒再走 3 秒，可在第 5 秒到位。
「跟隨步驟」恢復與步驟同步。移動可超過步驟邊界，單步預覽會等該步所有行動完成。
同一演員的動作重疊會在「檢查走台」中提示。時間軸上選中的色條用左右鍵前後微調 0.1 秒，Shift 為 1 秒。
步驟模式按先後次序和時長演示；時間模式按音樂絕對秒數播放。
時間軸上的「＋ 動作」、上方「新增動作」和 N 都在目前播放指針處新建，已有動作時間保持不變，指針留在原處。原先按步驟編排的曲目新增動作時會保留已有開始時刻，轉為按音樂時間編排；可復原。
播放按鈕旁的「逐步暫停」可一鍵切成「連續播放」，統一忽略本場所有曲目的步驟結束暫停。再次點擊恢復原有設定；此開關會隨演出包儲存。「播放設定」中也可調整，「預覽本步」始終會在本步完成時停止。

音樂、歌詞與排練
每首可匯入一份 MP3。逐句歌詞可匯入 JSON，或「12.3 - 16.8 | 歌詞」文字。
接入音樂時會先檢查能否讀取，新檔案成功接入後才替換原音樂；失敗時保留原檔案。更換音樂可復原。
音樂狀態會顯示「讀取中」「已就緒」或「未連接」。只有讀到可播放的音訊數據才顯示就緒；唯讀到時長不算連接成功。長時間沒有開始播放會提示重新連接，避免計時卡在零卻顯示正在播放。未連接時可重新連接或重試，也可明確選擇「靜音走台」。讀取過程中點擊播放會等音樂就緒；切換曲目或暫停會取消待播放請求。
歌詞現在獨立顯示在舞台旁，下方時間軸和右側演員動作可同時編輯；小窗口中歌詞欄顯示在舞台下方。
點擊歌詞可定位到對應時間與步驟，並保留選中的演員；點「編輯」直接修改歌詞、秒數和備註。文字輸入會立即保留，刪除和修改可復原。改開始時間會保持該句原時長，也可單獨修改結束時間。
「跟隨播放」會高亮並跟隨目前句；手動滾動暫時停止跟隨，再點按鈕可恢復。頂部「歌詞」按鈕可收起或展開。
排練模式選自己的角色，查看目前行動和下一次行動；獨立歌詞欄顯示目前歌詞，長期筆記可展開。
無音樂或歌詞也可編排；播放設定可調整速度、倒數和循環。
「檢查走台」會先暫停音樂，再按演員、步驟名稱和時間顯示問題，點擊即可定位修改。穿牆路線可在演員面板選擇「經過上下場口」，把入口加入路線；複雜路線仍可手動新增經過點。未完成的走台也允許儲存。
「放大舞台」保留歌詞和動作面板，擴大擺位空間；「展開時間軸」或拖動顯眼的分隔條調整時間軸高度。

更多設定與 AI
「更多」中有完整說明、演出管理、面板佈局和外部檔案重新載入。
全場角色名單和固定舞台由曲目共用；自由筆記可關聯多位角色。
先儲存界面編輯，再讓 AI 修改「演出资料」中的 JSON；完成後點「讀取資料夾最新版本」。
應用發現外部修改時會阻止覆蓋；可先把目前工作區匯出為另一份 ZIP。
格式指南和檢查工具都在「演出資料 / 技術資料」中，日常使用無需打開。

時間軸支援雙指捏合縮放；橫向雙指滑動瀏覽時間軸。空白編排可直接輸入較後時間；延長顯示不會延長播放時長。撤銷與重做路徑節點會保留編輯模式。
