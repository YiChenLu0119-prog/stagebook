# Roadmap

Stagebook is being developed gradually from real blocking and rehearsal work. The current release is a preview; this page records directions for further exploration, not promised features or dates.

## Available in this preview

- Local stage and timeline editing with independent actor timing.
- Lyrics alongside blocking, action notes and actor-focused rehearsal.
- Portable production packages, Undo/Redo and path checks.
- English, Simplified Chinese and Traditional Chinese interfaces.

## Areas for future updates

- Refine the first-time workflow through more rehearsals and hands-on testing.
- Improve editing comfort and workspace layouts across different screen sizes.
- Expand regression coverage, browser checks and file compatibility testing.
- Improve translation wording and accessibility, and evaluate additional languages with contributors.
- Grow the documentation and add generic examples that are suitable for public sharing.

The order and scope will be shaped by usage and feedback. No delivery dates are committed.

## Help shape the next version

Open an Issue with the task you were trying to complete, the exact point of friction and the result you expected. A small reproduction using the generic example is more useful than a broad feature list. Translation suggestions should identify the screen and the phrase in context.

Release notes will record completed changes. Use this roadmap to discuss future directions.
