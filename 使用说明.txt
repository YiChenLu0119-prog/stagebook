走台本 · 多语言版 v9.0

界面语言
顶部可切换「简体中文 / 繁體中文 / English」。首次按浏览器语言选择，也会记住你自己的设置。
语言切换保留播放指针、当前步骤、选择与时间轴缩放；不修改歌词、角色名称、动作备注等演出文字。
导出 HTML 会带上当时的界面语言；对方浏览器已有的个人语言选择优先。各语言均离线可用。

打开与保存
解压后只有「走台本.html」和「演出资料」两个入口。
用浏览器打开「走台本.html」。应用完全离线。
打开即载入包内走台、歌词与音乐。要继续其他版本，点「导入走台」选择完整文件夹或 ZIP。旧演出包仍可导入。
⌘ / Ctrl + S 保存：已连接文件夹时写回；未连接时可下载演出包。已有 JSON 会先备份。
发给演员：点「发给演员」下载 ZIP，对方解压后按同样方式打开并导入资料。
浏览器恢复草稿用于意外恢复；正式保留请保存文件。

编排一小步
1. 点下方步骤卡片，或用上方步骤选择框切换。
2. 拖动演员摆落点；淡色圈是起点。选中演员，右侧写「本步动作备注」。
3. 拖路线中间的圆点改弯度；要经过多个位置，点右侧「路径节点」。
4. 定位到需要的音乐时间，点「＋ 添加动作」或按 N；所有入口都在播放指针处新建，保留当前时间轴或步骤视图。点「预览本步」检查。
拖动落点、写备注和调整演员时长都不会移动音乐指针；本步开始与结束时间一直显示在上方。
Shift + 点击或从空白处拖框可多选，整体移动或排列站位。多人动作说明会写到各人的本步动作里，并保留已有备注。旧版共同提醒仍会显示在对应演员旁。
右侧方向微调和「移到指定位置」可按舞台区域摆位，无需输入坐标。
「舞台工具」可对照起点和落点、显示全部路线、开网格、旋转与调整舞台。
「衔接下一条路线」默认开启：调整落点时衔接原本相连的下一段起点，保留后续落点。

删除与右键
当前步骤旁直接有「删除本步」，无需进入详情。
选步骤按 Delete / Backspace 删步骤；选演员则删他在本步的行动，保留角色名单。
点「路径节点」后，点选中间经过点再按 Delete，或点列表旁的「删除」。起点和终点保留。
选弯度控制点按 Delete 可恢复该段直线。每种删除都能用 ⌘ / Ctrl + Z 撤销。
右键步骤、演员、路线或节点，可直接预览、复制、改时间、添加节点或删除。

常用快捷键
空格：播放 / 暂停；Shift + 空格：预览本步。
[ / ] 或 PageUp / PageDown：上一步 / 下一步；Home / End：首步 / 末步。
N：在当前播放位置添加动作，保留当前视图；⌘ / Ctrl + D：复制当前步骤；F2：重命名。
方向键：微调所选演员或节点；Shift 加大幅度。没选演员时左右切步骤。
⌘ / Ctrl + A：全选；⌘ / Ctrl + C / V：复制 / 粘贴站位。
E：路径节点；V：返回摆位；Esc：关闭菜单或逐级取消选择。
⌘ / Ctrl + Z：撤销；⌘ / Ctrl + Shift + Z：重做。
⌘ / Ctrl + O：导入；⌘ / Ctrl + K：搜索。
+ / − / 0：放大 / 缩小 / 适配当前视图；?：查看完整快捷键表。
输入框内保留正常的打字、文字删除、复制粘贴和文字撤销。

时间轴与演员移动时间
切到「时间轴」，用滑杆、＋ / − 横向放大，播放指针会留在视野中；⌘ / Ctrl + 滚轮围绕鼠标位置缩放，0 适配整曲。点击底部时钟可直接输入「01:25.6」或秒数定位。
演员色条：拖中间改开始时间，拖两端改起止时间，不会移动整个步骤或其他演员。
选演员后，右侧「移动时间」可设置开始前等待和移动用时。例如一步 10 秒，等待 2 秒再走 3 秒，可在第 5 秒到位。
「跟随步骤」恢复与步骤同步。移动可超过步骤边界，单步预览会等该步所有行动完成。
同一演员的动作重叠会在「检查走台」中提示。时间轴上选中的色条用左右键前后微调 0.1 秒，Shift 为 1 秒。
步骤模式按先后次序和时长演示；时间模式按音乐绝对秒数播放。
时间轴上的「＋ 动作」、上方「添加动作」和 N 都在当前播放指针处新建，已有动作时间保持不变，指针留在原处。原先按步骤编排的曲目添加动作时会保留已有开始时刻，转为按音乐时间编排；可撤销。
播放按钮旁的「逐步暂停」可一键切成「连续播放」，统一忽略本场所有曲目的步骤结束暂停。再次点击恢复原有设置；此开关会随演出包保存。「播放设置」中也可调整，「预览本步」始终会在本步完成时停止。

音乐、歌词与排练
每首可导入一份 MP3。逐句歌词可导入 JSON，或「12.3 - 16.8 | 歌词」文本。
接入音乐时会先检查能否读取，新文件成功接入后才替换原音乐；失败时保留原文件。更换音乐可撤销。
音乐状态会显示「读取中」「已就绪」或「未连接」。只有读到可播放的音频数据才显示就绪；只读到时长不算连接成功。长时间没有开始播放会提示重新连接，避免计时卡在零却显示正在播放。未连接时可重新连接或重试，也可明确选择「静音走台」。读取过程中点击播放会等音乐就绪；切换曲目或暂停会取消待播放请求。
歌词现在独立显示在舞台旁，下方时间轴和右侧演员动作可同时编辑；小窗口中歌词栏显示在舞台下方。
点击歌词可定位到对应时间与步骤，并保留选中的演员；点「编辑」直接修改歌词、秒数和备注。文字输入会立即保留，删除和修改可撤销。改开始时间会保持该句原时长，也可单独修改结束时间。
「跟随播放」会高亮并跟随当前句；手动滚动暂时停止跟随，再点按钮可恢复。顶部「歌词」按钮可收起或展开。
排练模式选自己的角色，查看当前行动和下一次行动；独立歌词栏显示当前歌词，长期笔记可展开。
无音乐或歌词也可编排；播放设置可调整速度、倒数和循环。
「检查走台」会先暂停音乐，再按演员、步骤名称和时间显示问题，点击即可定位修改。穿墙路线可在演员面板选择「经过上下场口」，把入口加入路线；复杂路线仍可手动添加经过点。未完成的走台也允许保存。
「放大舞台」保留歌词和动作面板，扩大摆位空间；「展开时间轴」或拖动显眼的分隔条调整时间轴高度。

更多设置与 AI

全场角色名单和固定舞台由曲目共用；自由笔记可关联多位角色。
