# Stagebook product context

Stagebook is an offline blocking and rehearsal editor for musical theatre, plays, and student productions. Directors can adjust actors’ paths and timing against lyrics without losing the playhead. Performers can practice their blocking or voice parts. Lighting operators can run cues against song time and stage sketches. A portable production package keeps rehearsal materials together for handoff.

Stagebook 10.1 supports English, Simplified Chinese, Traditional Chinese, Japanese, and Spanish. The desktop browser app works without an account or an internet connection. The software uses GPL-3.0-only. The offline app bundles a generic demo, and a separate production library is available from the release page.
